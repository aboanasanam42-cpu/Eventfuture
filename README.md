# مؤشر البيتكوين — BTC/USDT

تطبيق أندرويد باللغة العربية لمراقبة سعر BTC/USDT، عرض شموع السوق، ومراجعة مؤشرات EMA وRSI على أطر زمنية متعددة.

## البناء والتنزيل
- يتم بناء APK تلقائيًا عبر GitHub Actions عند الدفع إلى فرع `main`.
- افتح تبويب Actions ثم أحدث تشغيل **Android APK Build**.
- بعد نجاح البناء، نزّل Artifact باسم `BitcoinSignal-Android15-APK` وثم فك ملف ZIP لتجد `app-debug.apk`.

## مصادر البيانات
يستخدم التطبيق واجهة Binance العامة لبيانات الأسعار والشموع ولا يحتاج مفاتيح API لعرض السوق. توجد روابط إلى Binance Futures وMEXC Futures وCoinDesk وReuters وCoinGlass وTradingView.

## الأمان والقيود
- التطبيق لا يستخدم مفاتيح تداول خاصة ولا ينفذ أوامر تداول.
- التحليل الفني احتمالي ولا يضمن التنبؤ أو الربح.
- تُحفظ أسرار GitHub وإعدادات المستودع خارج ملفات المصدر؛ لا تضع مفاتيح خاصة في الكود أو في ملفات عامة.
